# railway-slack-altgraph

Code, data and logs for the paper

> H. A. H. Al-Naffakh, F. A. Majeed. *Bottleneck-Targeted Timetable Slack in Alternative-Graph Train Rescheduling: Validation on a Published Station Instance.* ISCKU 2026 (submitted).

Every number in the paper is regenerated by the scripts in `code/`.

## Requirements
Python 3.10+, `pip install "pulp<4" numpy scipy matplotlib`. The MILP solver is CBC (bundled with pulp).

## Layout
| Folder | Content |
|---|---|
| `code/` | `railsched.py` (alternative-graph engine: longest paths, positive-cycle check, propagation branch-and-bound, MILP), and one script per experiment (see table below) |
| `results/` | CSV result files read by the paper's tables |
| `figures/` | Figures 1–4 of the paper (`figs.py`, `fig_altgraph.py`, `fig_bts.py`) |
| `logs/` | CBC solver logs for Table 7 and the slack-experiment run logs |

## Script → paper mapping
| Script | Paper item |
|---|---|
| `dariano_table1_exact_reproduction.py` | Table 1 (reproduction of D'Ariano et al. 2005, Table 1: 41/31/18 s) |
| `enumerate_32.py` | Section 4.2 (all 32 selections, 6 feasible) |
| `btf_on_dariano.py`, `check_hyp.py` | Tables 2–3, Figure 3 (slack allocations on the published instance) |
| `slack_bench.py`, `slack_final.py` | Table 4 (targeted vs uniform vs sequential on 20 corridors) |
| `benchmark_statistics.py` | Table 6 (AMCC / FCFS gaps, exact Wilcoxon tests) |
| `scale_proof.py`, `realistic.py` | Table 7 (larger corridors; proof status read from CBC logs) |
| `exact_makespan_verification.py`, `rank_one_sharpness_tests.py` | Section 7 (Proposition 1 checks, two-train counterexample) |
| `equiv.py` | Section 6.1 (propagation B&B vs MILP agreement) |

## Reproducing
```bash
cd code
python dariano_table1_exact_reproduction.py   # prints 41 31 18
python enumerate_32.py
python check_hyp.py
python slack_final.py
python benchmark_statistics.py
python scale_proof.py                         # long: up to 300 s per instance
```
